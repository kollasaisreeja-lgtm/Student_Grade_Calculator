# Student Grade Calculator

## Project Overview
This Python project calculates a student's grade based on marks entered by the user.

## Features
- Accepts student name and marks.
- Calculates grades using if-elif-else.
- Validates marks between 0 and 100.
- Handles invalid inputs using a while loop.
- Displays encouraging messages.

## Grading System
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: 0-59

## Technologies Used
Python

## How to Run
Run grade_calculator.py using Python.
